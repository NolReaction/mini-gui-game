# Mini GUI Game — угадай число

Ранний учебный проект на C++ и SFML: пользователь загадывает число, а программа уточняет его по ответам «больше» и «меньше». Код игры написан автором самостоятельно, без ИИ, для практики событий, отрисовки и простого алгоритма поиска.

**Статус:** историческая работа. Исходная реализация сохранена как часть пути обучения C++ и графическим приложениям.

## Как играть

1. Загадать число от 0 до 1000 и нажать **Enter**.
2. Программа начинает с 500.
3. Нажать зелёную **`>`**, если загаданное число больше показанного, или красную **`<`**, если меньше.
4. После каждого ответа программа сужает диапазон и выбирает его середину.

В этой версии нет кнопки подтверждения угаданного числа или перезапуска раунда. Обработка противоречивых ответов также не реализована.

## Что внутри

**C++ · SFML 2.6.1 · Visual Studio / MSVC.**

- [main.cpp](main.cpp) — цикл событий, состояние диапазона, кнопки и отрисовка. Класс `CreateNewText` инкапсулирует текст как `sf::Drawable`.
- [Mini-Gui-Game.sln](Mini-Gui-Game.sln) и [Mini-Gui-Game.vcxproj](Mini-Gui-Game.vcxproj) — решение и настройки сборки Visual Studio.
- [include/SFML](include/SFML) и [lib/SFML](lib/SFML) — заголовки и библиотеки SFML, использовавшиеся в проекте.
- [font](font) и [image](image) — шрифт и иконка окна.

SFML — сторонняя библиотека; утверждение о самостоятельной разработке относится к коду игры.

## Сборка и запуск

1. Установить Visual Studio 2022 с компонентом разработки классических приложений на C++, toolset `v143` и Windows SDK 10.
2. Открыть `Mini-Gui-Game.sln`.
3. Выбрать **Debug**. В проекте пути к SFML и зависимости настроены для Debug; архитектура конфигурации должна совпадать с архитектурой библиотек SFML.
4. Для динамической сборки разместить совместимые DLL SFML 2.6.1 рядом с исполняемым файлом или добавить их каталог в `PATH`. В репозитории DLL нет; набор библиотек должен соответствовать MSVC, архитектуре и Debug-конфигурации.
5. Указать корень проекта рабочим каталогом в настройках отладки: программа читает `font/ALGER.TTF` и `image/crypto64.png` по относительным путям.
6. Собрать и запустить проект.

Это исходный Windows-проект, без отдельной конфигурации CMake и автоматизированных тестов. Он демонстрирует базовую работу с GUI и алгоритмом деления диапазона пополам; полноценный игровой цикл с валидацией ответов остался за рамками учебной версии.
