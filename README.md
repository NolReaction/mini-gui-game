# Mini GUI Game

Я сделал небольшую игру на C++ и SFML, которая угадывает загаданное мной число по подсказкам «больше» и «меньше». Это одна из моих ранних работ: я писал её сам, без ИИ, чтобы разобраться с графическим окном, обработкой событий и отрисовкой.

Я оставил проект в исходном виде как часть своей истории обучения. В нём ещё нет подтверждения угаданного числа, перезапуска раунда и проверки противоречивых ответов.

## Как играть

Загадай число от 0 до 1000 и нажми Enter. Игра начнёт с 500. Если твоё число больше показанного, нажми зелёную `>`, если меньше, красную `<`. После каждого ответа программа сужает диапазон и берёт его середину.

## Код

Вся логика находится в [main.cpp](main.cpp): цикл событий, границы диапазона, кнопки и отрисовка. Для текста я сделал класс `CreateNewText`, унаследованный от `sf::Drawable`.

Я использовал SFML 2.6.1 и Visual Studio / MSVC. В репозитории остались [решение Visual Studio](Mini-Gui-Game.sln), [настройки проекта](Mini-Gui-Game.vcxproj), [заголовки SFML](include/SFML), [библиотеки](lib/SFML), [шрифт](font) и [иконка](image). SFML является сторонней библиотекой, самостоятельно я писал именно код игры.

## Сборка

1. Установи Visual Studio 2022 с разработкой классических приложений на C++, toolset `v143` и Windows SDK 10.
2. Открой `Mini-Gui-Game.sln` и выбери Debug. Пути и зависимости SFML настроены для этой конфигурации. Архитектура сборки должна совпадать с архитектурой библиотек.
3. Положи совместимые DLL SFML 2.6.1 рядом с исполняемым файлом или добавь их каталог в `PATH`. DLL в репозитории нет; нужен набор под выбранные MSVC, архитектуру и Debug-конфигурацию.
4. В настройках отладки укажи корень проекта рабочим каталогом. Игра загружает `font/ALGER.TTF` и `image/crypto64.png` по относительным путям.
5. Собери и запусти проект.

Сборку я настраивал под Windows. Отдельной конфигурации CMake и автоматизированных тестов здесь нет.
